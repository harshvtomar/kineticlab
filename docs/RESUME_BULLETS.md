**KineticLab — Interactive 3D Mechanics Laboratory**  
React, TypeScript, Three.js, React Three Fiber, Rapier, Zustand, Vitest  
GitHub: https://github.com/harshvtomar/kineticlab

- Implemented interactive ramp, domino and lever experiments with adjustable physical parameters, collision telemetry and a revolute-joint seesaw model linking simulated motion to idealized torque calculations.
